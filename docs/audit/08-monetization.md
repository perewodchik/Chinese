# 8. Монетизация

[← к плану](README.md)

## Сравнение

Расходы сайта устроены так: чтение, карточки, библиотека, печать, курс
звуков почти ничего не стоят (статические файлы и одна строка в базе). Стоят
денег **три вещи**, и все — за каждое использование: озвучка (MiniMax,
$60–100 за миллион символов), оценка произношения (SpeechSuper, $0.006 за
предложение и минимум $20 в месяц), и, если появится, ИИ на сервере (T10).
(Цены — из проверки 5 ноября 2026 в старом плане; перед запуском проверить
заново.)

| | Реклама | Подписка | Кредиты (пакеты) |
|---|---|---|---|
| Доход при 100 активных учениках | центы в день | предсказуемый | неровный |
| Соответствие расходам | никакого | плохое: расходы переменные, один активный ученик съедает подписку десятерых | точное: платит тот, кто тратит |
| Порог входа для ученика | нет | высокий: платить каждый месяц за сайт, который он ещё не знает | низкий: купил раз, тратит когда хочет |
| Что ломает | внимание при учёбе; CSP (внешние скрипты); приватность; правило сайта «ничего не отвлекает»; на iPad в Safari блокируется | надо постоянно доказывать ценность; отмены, возвраты, напоминания | надо показывать цену у кнопки; риск «жалко тратить» |
| Сложность | низкая | высокая (периоды, отмена, льготный срок, вебхуки) | средняя (книга кредитов, покупка) |
| Вердикт | **нет** | позже, как надстройка | **да, первой** |

## Рекомендация

**Бесплатная основа + кредиты на платные действия + пробный запас. Свой
ключ остаётся бесплатной альтернативой. Подписка — потом, как «кредиты
каждый месяц и чуть больше».**

- **Бесплатно навсегда:** чтение каталога и своих текстов, карточки,
  библиотека, печать, курс звуков, запись и сравнение своего голоса,
  готовая озвучка текстов каталога (K14), добавление текста с черновиком
  (T3), дополнение через свой чат Claude (T4).
- **За кредиты:** оценка произношения, озвучка своих текстов, озвучка
  отдельных строк и слов рассказчиком, позже — дополнение текста одной
  кнопкой (T10) и очередь «фото → текст» (T5).
- **Пробный запас** при регистрации — чтобы попробовать всё платное.
- **Свой ключ** (MiniMax; SpeechSuper — кто сможет) — кредиты не тратятся.
- **Админ** — без кредитов и лимитов, проверка роли на сервере (A1).

Единица — **1 кредит ≈ 1 цент себестоимости с запасом**, чтобы цены у
кнопок были целыми и понятными. Примерная шкала (числа уточнить по
фактическим ценам поставщиков в момент работы):

| Действие | Себестоимость | Кредитов |
|---|---|---|
| Оценить фразу | ~$0.006 | 1 |
| Озвучить текст, 300 символов | ~$0.02–0.03 | 3 |
| Озвучить строку отдельно | < $0.005 | 1 за 3 строки (считать по символам, списывать с округлением вверх раз в день) |
| Пробный запас | ~$0.5–1 | 100 |
| Пакет «малый» | — | 500 за ~$5 |
| Пакет «большой» | — | 1500 за ~$12 |

Минимум SpeechSuper $20 в месяц — постоянный расход владельца независимо
от числа учеников; заложить в цену пакетов и не открывать оценку за кредиты,
пока платящих меньше, чем нужно для его покрытия (выключатель в A11).

## Задачи

<a id="m1"></a>
### M1 (В) (владелец) Решения до кода

1. **Модель**: согласиться с рекомендацией или выбрать другую.
2. **Платёжный сервис.** Зависит от страны владельца и учеников:
   - сервис «продавец записи» (Paddle, Lemon Squeezy) сам платит НДС разных
     стран и выставляет чеки — проще всего одному человеку;
   - Stripe — дешевле, но налоги на владельце, и недоступен для
     резидентов РФ;
   - для учеников из РФ — отдельный местный сервис (ЮKassa, CloudPayments)
     и самозанятость/ИП.
   Агент готовит сравнение по актуальным условиям в момент работы;
   выбирает владелец.
3. **Тариф Vercel.** Бесплатный тариф Hobby не допускает коммерческого
   использования — перед приёмом денег нужен Pro (проверить условия).
4. **Правовое.** `/privacy`, `/terms` (L1), условия возврата, кто продавец.
   Удалить 12 записей голосов под CC BY-NC (`public/voices/CREDITS.md`) —
   в старом плане (L2) записано: «можно, пока сайт бесплатный».
5. **Цены** пакетов и размер пробного запаса.

<a id="m2"></a>
### M2 (В) Книга кредитов на сервере

- Таблица `credit_ledger(id, user_id, delta, reason, ref, created_at,
  created_by)` — **только добавление строк**, никогда `UPDATE`/`DELETE`.
  `reason`: `trial`, `purchase`, `admin_grant`, `spend:speechsuper`,
  `spend:minimax`, `refund`. `ref` — id платежа или вызова, с уникальным
  индексом `(reason, ref)` — повторный вебхук или повторный запрос не
  начислит и не спишет дважды.
- Баланс — `SUM(delta)`; для скорости — `credit_balances(user_id, balance)`
  с обновлением в той же транзакции и проверкой `balance >= 0` в базе.
- Списание: `spend(userId, amount, reason, ref)` — одна транзакция
  `UPDATE … SET balance = balance - $1 WHERE user_id = $2 AND balance >= $1`
  + строка в книге; 0 строк обновлено → `needs_credits`.
- Клиент баланс **только читает** (`GET /api/account/credits`). Ни один
  маршрут не принимает от клиента сумму начисления.
- При удалении аккаунта книга остаётся обезличенной (нужна для учёта).

**С чего начать.** По образцу `usage-service.ts` и таблицы `api_usage`;
порты в `server/src/application/ports.ts`; обе базы (Postgres и SQLite);
тесты на гонку двух списаний (pglite уже есть в `server/test/pglite.ts`).

<a id="m3"></a>
### M3 (В) Пробный запас

При создании аккаунта — строка `trial` (+N). Защита от «новый аккаунт —
новый запас»: регистрация по приглашениям уже есть; при открытой
регистрации запас выдаётся после первого завершённого текста, а не сразу, и
не больше одного на приглашение. Размер — в `site_settings` (A11).

<a id="m4"></a>
### M4 (В) Списание в местах вызова

Через `paid-access` (K13): сначала **резерв** (списать), затем вызов
поставщика, при ошибке поставщика — **возврат** (`refund` с тем же `ref`).
Ответ из кэша (уже озвученный текст) не стоит ничего. Места:
`speech-eval-service.ts` (`evaluate`), `narration-service.ts` (`text`,
`preview`, `readOwn`, `tryDesigns`).

<a id="m5"></a>
### M5 (В) Цена у кнопки

Правило: платное действие показывает цену **до** нажатия и остаток после.
Компонент `PaidAction` (K13). Без модальных окон на каждое действие;
подтверждение — только для дорогого (> 10 кредитов). Когда кредиты
кончились — на месте кнопки: что осталось бесплатным (голос устройства,
сравнение записи) и ссылка «Get more».

<a id="m6"></a>
### M6 (В) Покупка

- `POST /api/billing/checkout { pack }` → сервер создаёт сессию оплаты у
  сервиса и возвращает адрес; клиент **переходит** на страницу сервиса (без
  их скрипта на сайте — CSP не меняется, SEC20).
- `POST /api/billing/webhook` — без сессии, проверка подписи сервиса по
  секрету из окружения, идемпотентность по id события; начисляет кредиты
  (`purchase`, `ref` = id платежа). Исключить маршрут из `sameOriginOnly`
  (это запрос не из браузера) — и только его.
- Страница возврата «Thank you» читает баланс; начисление делает только
  вебхук, не страница.
- Таблица `payments(id, user_id, provider, provider_id, pack, amount,
  currency, status, created_at)`.

<a id="m7"></a>
### M7 (С) Страница «Credits»

`/account/credits`: остаток, история (дата, что, сколько), пакеты, «Use
your own key instead» → `/settings/keys`. Остаток — одной строкой в профиле
(P12) и в листе Me.

<a id="m8"></a>
### M8 (С) Админ: кредиты

В карточке пользователя (A5): баланс, история, **Grant credits** (с
причиной, в журнал A2, с повторным вводом пароля SEC7). Сводка: продано,
потрачено, себестоимость по сервисам за месяц (A10).

<a id="m9"></a>
### M9 (С) Админ и особые аккаунты без списания

`users.role = 'admin'` → `paid-access` не списывает. Для друзей — флаг
`unlimited` в карточке пользователя (это K10 старого плана), с дневным
потолком расхода.

<a id="m10"></a>
### M10 (С) Потолки сайта

Чтобы ошибка или злоупотребление не опустошили ключ владельца: дневной
потолок расхода сайта по каждому сервису (`site_settings`), по достижении —
платные действия за кредиты выключаются с честным сообщением, свои ключи
работают. Строка-предупреждение в `/admin`.

<a id="m11"></a>
### M11 (Н) Подписка «Supporter» — потом

Когда есть платящие: ежемесячно N кредитов + ранний доступ к новым книгам.
Реализуется поверх той же книги (`reason: subscription`), вебхуки периода —
у того же сервиса. Не делать, пока пакеты не показали спрос.

<a id="m12"></a>
### M12 (Н) Чего не делать

- Рекламу — ни баннеров, ни «партнёрских» блоков.
- Платный доступ к чтению и карточкам — основа бесплатна.
- Сгорающие кредиты, «энергию», таймеры и прочее давление: это
  противоречит правилу сайта «ничего, что считает пропущенное».
- Хранение карт или любых платёжных данных у себя.
